# Сторонние компоненты

- Панель просмотра видео использует компонент **OBS Browser**, уже входящий в OBS Studio. Интерфейс `src/obs_browser_panel.hpp` взят из [obsproject/obs-browser](https://github.com/obsproject/obs-browser/blob/85c7f2668936679b43329a9ee9f1e269d9bac812/panel/browser-panel.hpp) для OBS 33. Код OBS Browser распространяется по GPL-2.0-or-later.
- Логотипы DonationAlerts и DonatePay используются только для обозначения источника доната. Они принадлежат соответствующим сервисам.
